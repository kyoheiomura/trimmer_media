# tocotoco（とことこ｜トリマーメディア）

サイト名の tocotoco（とことこ）は、犬が歩く音。「この人のところなら、とことこ通いたくなる」と思えるトリマーに出会えるように、という意味を込めている。トリマーに「とことん」話を聞くメディア、という意味も重ねている。ロゴのしるしは、歩いていく2つの足あと。

犬や猫のトリマーへのインタビューを軸にした「トリマーを読んで選べる」メディア。
コンセプトは **あずけるのは、どんな人だろう。**（トリマーの声を読んでから選ぶ） はさみの入れ方も、怖がる子への声のかけ方も、人によって違うので、星・口コミ・ランキングでは並べない。判断材料は「インタビュー本文」と、当日の流れ・料金・サロン情報などの「予約の前に知りたいこと」。

ジムトレーナーのメディア「バディ」（`../gym-coach`）と同じ仕組みを土台にし、トリマー向けに作り替えた姉妹サイト。デザインは別物。

- 取材の質問シート: [docs/interview-question-sheet.md](docs/interview-question-sheet.md)
- 原稿テンプレート: [templates/trimmer.mdx](templates/trimmer.mdx)・[templates/salon.yaml](templates/salon.yaml)

## 技術

Next.js（App Router・全ページ静的生成）／TypeScript／Tailwind CSS v4／MDX＋frontmatter（Zod で検証）。

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー（http://localhost:3000） |
| `npm run build` | 原稿の検査 → ビルド → title の検査。どれかで失敗したら止まる |
| `npm run lint:content` | 原稿の検査だけ（スキーマ・参照・NG ワード・情報の鮮度） |
| `npm run check:titles` | ビルド後の全ページの title に「トリマー」が入っているか |
| `npm run typecheck` | 型チェック |
| `FORCE=1 bash scripts/generate-photos.sh` | ダミーの写真を AI（Codex）で作り直す（FORCE なしなら、無い写真だけ作る） |

## トリマー・サロンを追加する

1. `templates/salon.yaml` を `content/salon/<slug>.yaml` にコピーして埋める（地域は `data/areas.ts` にある値だけ。無ければ市区町村を足す）
2. `templates/trimmer.mdx` を `content/trimmer/<slug>.mdx` にコピーして埋める。写真は `public/images/trimmer/`（縦 4:5）と `public/images/interview/`
3. `npm run lint:content` で検査 → `draft: false` にして公開
4. ファイル名が `_` で始まるものは読み込まれない（下書き置き場）。`SHOW_DRAFTS=1 npm run dev` で下書きも表示
5. 相談を増やすときは `data/vocab.ts` の `CONCERNS` に足す

## URL

| URL | 中身 |
|---|---|
| `/` | トップ（見出しと写真・トリマーさんのことば・新着・相談8つ・使い方・エリア・おまけの「なでてみる」） |
| `/trimmer/` | 一覧（フリーワード・相談・エリア・心配ごと・特徴で絞り込み。新着順／エリア順） |
| `/trimmer/<slug>/` | 取材記事＋仕事のしかたの項目＋お願いするには |
| `/concern/`・`/concern/<slug>/` | 相談から |
| `/area/`・`/area/<pref>/`・`/area/<pref>/<city>/` | エリアから（47都道府県） |
| `/salon/<slug>/` | サロンの情報と、そこで働くトリマー |
| `/join/`・`/privacy/` | 掲載希望の方へ・プライバシーポリシー |

## デザインの決まり

- トーンは「かわいくて、すっきり」。あたたかい白の地に、黒い文字とミントの面。差し色は黄色（しるしとマーカー）。押すものは黒
- 主役は犬とトリマーの写真と、トリマー本人の言葉。言葉はふきだし（`.bubble`）で見せる
- 書体は LINE Seed JP ひとつ（見出しとロゴは 800）
- カードと写真は大きめの角丸、ボタンとしるしは丸い端。色の面は、角の丸い大きなブロックで置く
- 小さな線画（はさみ・きらきら）はトップの写真のそばにだけ。フッターの犬猫のイラストは `scripts/generate-illust.sh` で作る
- 読みたくなる入口：トップの「トリマーさんの、ことば」（frontmatter の `hook`）、カードの「章の見出し」
- 動き：スクロールして画面に入った要素が、下からぽんっとはずんで現れる（`.reveal`／ふきだしやしるしは `.reveal-pop`）。トップの最初の画面は読み込み時に順にはずんで出て、黄色のマーカーが引かれる。ロゴの足あとは歩くように順に出る。動きを減らす設定では全部止まる
- スマートフォン：ヘッダーはロゴ・「さがす」・メニューのボタンだけ（`components/MobileMenu.tsx`）。トップの「ことば」は横にスワイプ。一覧の絞り込みは最初は閉じておく。本文は右端までそろえ、短い言葉（`.phrase`）だけ文節で折り返す
- 遊び：トップのいちばん下に「おまけ」として置く、なでられる毛並み（`components/CoatPlay.tsx`）。なでると毛が流れ、毛色を選べる
- 詳しくは `app/globals.css` の冒頭

## 守ること（コンセプトから）

- 口コミ・星・点数・ランキング・「人気順」「おすすめ順」は作らない。並び順は新着順とエリア順だけ
- 病気や皮膚のトラブルへの効果、仕上がりや動物の変化の約束は載せない（`data/ng-words.ts` で検査。診断と治療は獣医師の仕事。公開前・有料掲載の開始前に専門家の確認を受ける）
- コンテストの成績や担当した頭数など、肩書きの大きさを比べる項目は作らない
- 有料掲載でも表示順を変えない。`listing: paid` のトリマーには「掲載プラン利用」と自動で表示する
- 料金は通常の額だけ。割引・初回価格を強調しない

## 公開前にやること

- サイト名「tocotoco（とことこ）」の商標・同名サービスを確認する
- 公開する場所を決める（ほかの姉妹サイトと同じく media.raxus.inc 配下なら `/trimmer/` などのパスで配信する設定が必要）
- `data/site.ts` の `isDummyContent` を `false` にする（robots.txt の全面ブロックが外れる）
- `NEXT_PUBLIC_SITE_URL` を本番ドメインに設定する
- ダミーのトリマー・サロン（`content/`）と AI 生成の写真を、実際の取材内容と写真に差し替える（カード下の `SampleNote` も消す）
- プライバシーポリシーを確定する
